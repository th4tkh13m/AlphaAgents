Install Artemis dependencies with `uv sync` in this directory, then install AndroidWorld and its dependencies into the Python 3.12 environment. AndroidWorld's separate Python 3.11 environment cannot import Artemis's Python 3.12 source. On this host the existing `/data/khiem/Reproduce/artemis/.venv/bin/python` also supplies compatible dependencies; the runner prioritizes this repository's copied Artemis and eval AndroidWorld source on `sys.path`.

From the repository root, with a running AndroidWorld emulator:

```bash
OPENAI_API_KEY=EMPTY OPENAI_BASE_URL=http://localhost:8001/v1 \
  /data/khiem/Reproduce/artemis/.venv/bin/python eval/run_artemis_androidworld.py \
  --tasks ClockStopWatchRunning,ContactsAddContact \
  --serial emulator-5560 --console-port 5560 --grpc-port 8560 \
  --adb "$PWD/eval/android-sdk/platform-tools/adb" \
  --output-dir "$PWD/eval/results/artemis"
```

Run evaluations sequentially when sharing an emulator. Use `--artemis-config harness/artemis/config/androidworld_low_memory.jsonc` to select the source workspace's existing low-memory configuration. The model override for all roles is stored under `eval/`.
